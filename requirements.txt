# College ERP System Requirements
# 
# This project is built entirely using the Python Standard Library.
# It does not require any third-party external dependencies (e.g., no pip install needed).
# 
# Core built-in libraries used:
# - http.server / socketserver (for the backend web server)
# - sqlite3 (for the database)
# - json, os, re, base64, hashlib, uuid (for utilities and security)
# - zipfile, xml.etree (for parsing .xlsx files without pandas/openpyxl)
# 
# Instructions:
# Simply run the application using Python 3:
#   python app.py
